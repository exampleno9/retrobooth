# RetroBooth (prototype)

A photobooth in the browser: snap a 4-pose photo strip (2×6 in) or a Polaroid (3.5×4.25 in), preview it, and order real prints delivered home. No downloads, only prints.

This is a front-end prototype. Payments and order fulfilment aren't connected yet. The camera needs HTTPS, so open it from the GitHub Pages link rather than as a local preview.
